# Burak Keskin

I build reproducible RNA-seq and bioinformatics workflows that turn research data into clean tables, publication-ready figures, and concise reports.

**Website:** [Insights From BioData](https://bioinformatikci.github.io/insights-from-biodata/)  
MSc student in Bioinformatics and Systems Biology at Gebze Technical University.

## Featured Work

- [RNA-seq Workflow](https://github.com/Bioinformatikci/rna-seq-workflow)  
  A DESeq2 differential expression workflow on the public airway dataset. One script produces the QC summary, result tables, plots, and a short report.

- [rMATS AD Skipped-Exon Analysis](https://github.com/Bioinformatikci/rmats-ad-skipped-exon-analysis)  
  A skipped-exon workflow for AD vs control RNA-seq data with high-confidence event tables and selected sashimi plots. CI checks the published tables against their summaries.

- [Bioinformatics Portfolio Projects](https://github.com/Bioinformatikci/bioinformatics-portfolio-projects)  
  Selected projects, including an interactive [iMAT tool](https://github.com/Bioinformatikci/bioinformatics-portfolio-projects/tree/main/imat-tool) and a [synthetic iMAT workflow](https://github.com/Bioinformatikci/bioinformatics-portfolio-projects/tree/main/splicing-pathogenicity-imat-demo). Each project lists its status and an output to inspect.

## Metabolic Modeling

- [GEMsplice HumanGEM Alzheimer Analysis](https://github.com/Bioinformatikci/gemsplice-humangem-alzheimer-analysis)  
  Alzheimer/control transcriptomics connected to Human-GEM metabolic modeling, with summary tables, figures, and a final report.

- [Human-GEM GIMME Alzheimer Analysis](https://github.com/Bioinformatikci/humangem-gimme-alzheimer-analysis)  
  Context-specific AD and control models from Salmon outputs, with precomputed results, QC reports, and figures.
