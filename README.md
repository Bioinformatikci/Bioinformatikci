# Bioinformatikci

I build reproducible bioinformatics workflows, RNA-seq analysis pipelines, alternative splicing summaries, metabolic-modeling workflows, and publication-ready visualizations.

## Focus Areas

- RNA-seq differential expression analysis
- Alternative splicing analysis with rMATS-style event review
- Genome-scale metabolic modeling workflows with Human-GEM resources
- Publication-ready plots: PCA, heatmap, volcano plot, sashimi plot, and pathway figures
- Functional enrichment, pathway interpretation, and reproducible reporting
- Python, R, Bash, and MATLAB workflow automation for research data handling

## Featured Work

- [RNA-seq Workflow](https://github.com/Bioinformatikci/rna-seq-workflow)  
  A reproducible RNA-seq differential expression workflow with result tables, PCA, heatmaps, volcano plots, and a short report.

- [Insights From BioData](https://bioinformatikci.github.io/insights-from-biodata/)  
  A single-page bioinformatics service site focused on RNA-seq, alternative splicing, pathway interpretation, and publication-ready visualizations.

- [rMATS AD Skipped-Exon Analysis](https://github.com/Bioinformatikci/rmats-ad-skipped-exon-analysis)  
  A reproducible rMATS skipped-exon workflow for AD vs control RNA-seq data with high-confidence event tables and selected sashimi plots.

- [Human-GEM GIMME Alzheimer Analysis](https://github.com/Bioinformatikci/humangem-gimme-alzheimer-analysis)  
  A Human-GEM GIMME workflow for Alzheimer disease vs control transcriptomic metabolic model analysis with precomputed results, QC reports, and figures.

- [GEMsplice HumanGEM Alzheimer Analysis](https://github.com/Bioinformatikci/gemsplice-humangem-alzheimer-analysis)  
  A curated research-oriented workflow for Alzheimer/control transcriptomics and metabolic-modeling analysis.

- [Bioinformatics Portfolio Projects](https://github.com/Bioinformatikci/bioinformatics-portfolio-projects)  
  Selected bioinformatics portfolio projects covering RNA-seq, protein annotation, GEO analysis, Shiny dashboards, and Python utilities.

## Tools

My public portfolio focuses on research support, data analysis, visualization, and reproducible reporting. It does not provide clinical diagnosis, treatment decisions, or patient-specific medical interpretation.
