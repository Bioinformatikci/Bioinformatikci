# Bioinformatikci

I build reproducible bioinformatics workflows for transcriptomics, alternative splicing, metabolic-model analysis, and publication-ready research visualizations.

## Focus Areas

- RNA-seq differential expression analysis
- Alternative splicing analysis with rMATS-style event review
- Genome-scale metabolic modeling workflows with Human-GEM resources
- Reproducible reporting with R, Python, Bash, and MATLAB
- Research-ready figures including PCA, heatmaps, volcano plots, sashimi plots, and pathway-level summaries

## Featured Projects

- [RNA-seq Workflow](https://github.com/Bioinformatikci/rna-seq-workflow)  
  Reproducible DESeq2 RNA-seq workflow with QC outputs, DEG tables, PCA, heatmaps, volcano plots, and a structured summary report.  
  Tools: R, DESeq2, Bioconductor, ggplot2, pheatmap

- [rMATS AD Skipped-Exon Analysis](https://github.com/Bioinformatikci/rmats-ad-skipped-exon-analysis)  
  rMATS skipped-exon workflow for AD vs control RNA-seq data with compact result tables and selected sashimi plot examples.  
  Tools: STAR, rMATS, Python, Bash, rmats2sashimiplot

- [Human-GEM GIMME Alzheimer Analysis](https://github.com/Bioinformatikci/humangem-gimme-alzheimer-analysis)  
  Human-GEM GIMME workflow for Alzheimer disease vs control transcriptomic metabolic-model analysis with precomputed QC and comparison outputs.  
  Tools: Python, COBRApy, Gurobi, Human-GEM, Salmon

- [Insights From BioData](https://bioinformatikci.github.io/insights-from-biodata/)  
  Live portfolio site presenting RNA-seq, alternative splicing, pathway interpretation, and publication-ready visualization services.  
  Tools: HTML, CSS, JavaScript, GitHub Pages
